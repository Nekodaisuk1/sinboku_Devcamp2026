# 画面と言葉の方針

Build 20 で主画面をキャンバスにした。Build 19 の「縦に積んだはしご」は、下記の「時間の野原」に置き換える。

## このアプリを開く理由

**今後7年のうち、自分がいまどこにいて、次にどの扉が開くのかを確かめに来る。**

7年は、中3から大学2〜3年まで。そのあいだに決める場所は4つしかなく、今日決めるのはいちばん近い1つだけである。残りの時間は、好きなことを続けて、判断材料を増やすために使える。

進路を決めさせる作業や、自己分析を最初の動機にしない。診断・適合度・順位づけは持たない。

## 2つのタブ

| タブ | ルート | 役割 |
|---|---|---|
| 時間の野原 | `#now` | 縦軸＝時間のキャンバス。置いたものから線が伸び、学問が現れ、合流する |
| 探す | `#find` / `#find/<動詞>` | いまやっていること（動詞）から、活動・学問・掲載情報へ |

`#routes/<学問>` は経路の詳細で、「探す」から開く。タブは増やさない。

## 逆算の起点は動詞

中学生は学問名を持っていない。持っているのは「ゲームやってる」「料理する」である。だから入口を**動詞**にする。

```text
つくる／くらべる／観察する／調べる／伝える
  ↓ 同じ動詞が、好きなことをまたいで並ぶ
  ↓ その動詞を仕事や研究として続けている学問
  ↓ その学問にたどり着く4本の経路（#routes）
```

動詞の割り当てはこのアプリの編集である。画面にそう明記する。

## 言葉をそろえる

| 表示 | 意味 |
|---|---|
| 7年の地図 | 4つの分岐点と、いまの記録 |
| 分岐点 | 高校／文理・コース／学部・学科／専攻・研究室 |
| 保留できる期限 | その分岐点を決めずにいられる時期の目安 |
| いまの考え | 分岐点ごとに本人が残す1行。空欄が正常 |
| やったこと | 日付と1行だけの記録。進捗ではない |
| 動詞 | つくる・くらべる・観察する・調べる・伝える |
| できること | 動詞ごとの活動アイデア。募集案内ではない |
| 掲載情報 | 出典と確認日のある実在の教材・活動・学校 |
| あとで見る | 掲載情報の仮置き |

使わない言葉：「探究」「比較軸」「あなたに最適」「向いています」「達成率」「連続◯日」。「探究」は学校から与えられた課題を連想させるため、UIに出さない。

## 空欄の扱い

空欄は未達ではない。

- 分岐点の「いまの考え」が空なら「まだ決める段階ではありません」と表示する。
- 記録が0件なら「空のままで問題ありません」と表示する。
- 未入力の欄を数えたり、埋めるよう促したりしない。

## 学年

任意。1タップで選び、いつでも変更・取り消しができる。用途は分岐点までの残り月数を出すことだけで、それ以外の出し分けには使わない。未設定でも地図は全部見られ、残り月数だけが出ない。

推測しない。位置情報も学校名も尋ねない。

## 次のヒアリングで確認すること

1. 起動して30秒で「今日決めるのは1つだけ」と読み取れるか。
2. 7年という幅が、安心ではなく圧迫になっていないか。
3. 「いまの考え」の空欄が、未完了のタスクに見えていないか。
4. 動詞から、自分がすでにやっていることを選べるか。
5. 「やったこと」を書く気になるか。書かないまま閉じても平気か。
6. 経路4本を見て、どれかを勧められたと感じないか。

実装で達成を断定しない。対象者本人の利用観察は未実施。


## 時間の野原（Build 20）

主画面は一覧ではなくキャンバスにする。**一覧で書けることを図にしただけなら、図にする意味がない。**

### 軸の約束

- **縦だけが時間。** 下が今日、上が7年先。段は4つの分岐点と「いま」。
- **横に意味はない。** 本人がどこに置いてもよく、アプリは置き直さない。並べ替えも整列もしない。
- **意味を持つのは線。** 置いたものから伸びた線が、どこで合流するか。これが一覧では出せない唯一の情報である。

横位置を領域や確信度に割り当てない。割り当てた瞬間、「自分について勝手に何かをされる」側に落ちる。

### 世界は置いたぶんだけ現れる

初期状態は空。学問も経路も最初から並べない。

1. 「いま」に1つ置く → その興味が扱う領域が上の段に**現れ**、線が伸びる
2. 2つ目を置く → 同じ領域に2本届いたら、そこが**合流**として光る
3. 学問を選ぶ → そこへの経路を1本ずつ、中間の段に引ける
4. 未来の段にも置ける → 「高校に入ったらやりたい」を今日から持てる

合流した学問の横位置は、届いている置きものの平均にする。合流するほど、2つの間へ寄る。

### 合流しないことは失敗ではない

共通点が出なければ「まだ合流していません」と言い、無理に線をつながない。次にできること（別の興味を足す／関わり方を選ぶ）だけを出す。

### 図を読まなくても同じことが分かる

「一覧で読む」を常設し、段ごとの中身と合流を文章で読めるようにする。色だけに意味を持たせない。合流は色・枠線・印の3つで示す。

## 情報が増えたときの扱い（Build 22）

置くほど線とラベルが増える。読めなくすることは、野原の価値そのものを壊す。ただし**読みやすくするために横位置の原則を曲げない**。

### してよいこと

- **描くものを減らす**（表示切替）。ただし何件隠しているかを必ず言う。
- **まとめる**（「ほか◯件」）。線は消さず、まとめたチップへ付け替える。
- **一時的に行を分ける**（段ごとの「広げる」）。横位置は各自のまま、変わるのは行だけ。保存しない。

### してはいけないこと

- 保存された `x` を書き換える。
- 読みやすさを理由に自動整列・並べ替えをする。
- 横方向を意味（領域・確信度・新しさ）で分ける。
- 隠したことを黙る。件数を出さずに減らす。

### 選択したときの約束

1つ選んだら、そこから学問までの線を最後まで追える。選んだものと、その線が届く学問は「まとめ」に入れない。

**絞り込みも、隠さない範囲も、線1本ぶんにそろえる。** 置きものを選べばその学問まで、学問を選べばそこへ届いている置きものまで。合流相手（学問をまたいだ2ホップ先）は含めない。

- 含めると「選んだものだけ」が20件中16件になり、絞り込みとして働かない。
- 含めると、選んだ瞬間に段が一気に伸びて、どこを見ていたのか分からなくなる。

合流を見たいときは**学問のほうを選ぶ**。それが2ホップ目にあたる。図のうえでは、まとめから学問へ伸びる線が残るので、まとめに入っていても合流していること自体は読み取れる。

### 操作の同等性

マウス・タッチ・キーボードで同じことができる。置きものを動かす操作も含む（矢印キー：左右＝横位置、Shiftで細かく／上下＝段の移動）。段を移したときは、どの段へ動いたかを読み上げる。

### 言葉

| 表示 | 意味 |
|---|---|
| 全体を見る／選んだものだけ／最近置いたもの | 描くものの絞り込み。保存データは変わらない |
| ほか◯件 | その段でまとめて置いてあるもの。タップで展開 |
| 広げる／まとめる | その段だけ1ノード1行にする一時表示 |
| 広げている段 | 野原の外に常時出す。広げた段は縦に長くなり、見出しの「まとめる」が画面外へ出てしまうため |

「どちらも」は2件のときだけ使う。3件以上は「どれも」。名前を並べるのは3つまでにして、残りは件数で言う。
