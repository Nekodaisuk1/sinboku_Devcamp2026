# 画面と言葉の方針

## このアプリを開く理由

「好きなことはあるけれど、ほかに何ができるかは知らない」ときに使う。検索語を考えなくても地図から知らなかった楽しみ方に出会い、気になったものを残して次回その続きから探せる。進路を決めるための作業や自己分析を最初の動機にしない。

外部検索は、すでに知りたいものがあるときに強い。このアプリは、まだ名前を知らない活動や、別の場所・分野とのつながりを見渡す入口にする。外のページは出典として開き、戻ってきたときにも地図の位置を失わない。

## 言葉をそろえる

| 表示 | 意味 |
|---|---|
| 好きなこと | 音楽・海などの入口 |
| 楽しみ方 | 一緒に演奏する、外に出て観察するなど |
| 活動 | 一曲弾く、地域の観察会に行くなど |
| 気になるもの | 自分が残した情報 |
| 見つける | 選んだものの続きを見る |
| メモ | やってみたいこと・感想を残す |
| 整理する | 名前やつながりを変える |
| 並べて見る | 複数の情報を横に置く任意の操作 |

「問い」「比較軸」「探究」は、初回の操作を説明するラベルには使わない。学問・公式情報を説明する文中では意味上必要なら使える。

## 一つの画面

PCは地図と詳細を左右に、スマホは地図と詳細を上下に固定する。画面全体をスクロールさせず、詳細の中だけスクロールする。長いフォームや情報一覧を一度に全部表示するという意味ではない。

- 地図にはジャンルの入口を常に置く。
- 選択すると詳細のみ切り替える。閲覧履歴の情報も同じ詳細欄で開く。
- 地図の内容が同じなら、拡大率とスクロール位置を保つ。
- 狭い画面では選んだジャンル周辺を小さな地図として表示する。ほかのジャンルは常設の入口から開ける。
- 詳細の変化は約180〜200msの短い動きで示す。動きを減らす設定では無効にする。
- 設定、外部ページ、複数情報を並べる画面は必要に応じた別画面・ダイアログとして残す。

## 次のヒアリングで確認すること

説明なしで、30秒以内に一つの楽しみ方を開けるか。海から森・川にも行けると気づくか。前回の続きを自分で見つけられるか。メモを書かず眺めるだけでも使う理由があるか。これらは実装だけで達成を断定せず、利用者に確認する。
