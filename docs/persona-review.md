# シンボク：第三者レビュー（ペルソナ評価）

実施日：2026-09-12
対象：Build 18（`wireframe/`、`http://127.0.0.1:4317` を 390px 幅で実操作）
位置づけ：**指定されたペルソナに基づく分析であり、実在の中学生による利用観察ではない。** `self-evaluation.md` が挙げ続けている未達項目（本人観察）を代替するものではない。

---

## ペルソナ

中学3年生・男子。高校受験を控える。地元の公立中学校。父は単身赴任、兄は高専の寮生活のため、平日は母と2人暮らし。生活はほぼ自宅で完結し、行動範囲は家と近所の空き地。ゲーム、料理、ギター教室、Z会のタブレット学習（自由進度）が日常の中心。

内向的だが非社交的ではなく、人間関係では緩衝材になる。慎重で完璧主義寄り。自分から相談することはほとんどない。興味を持てば自分から試すが、一人だと続かない（英語塾・縄跳び・筋トレはいずれも三日坊主）。一度ハマると没頭する。自由に使える金額は週500円程度。

決定的に重要な点：

1. 進路について「めんどくさい」とぼやくが、興味がないわけではない。海洋系・生物学など、専攻として選びたい分野は実際に存在する。
2. **「自分について勝手に何かをされること」を最も強く嫌う。** 進路に限らず一貫して観察される、この人物の中心的行動原理。

---

## 総評

**設計思想は驚くほど正しく、コンテンツが致命的に足りていない。**

彼が嫌う「勝手に何かをされること」を、このサービスは構造で回避できている。診断なし・登録なし・適合度スコアなし・「あなたに向いています」なし・保護者共有の導線ごと撤去。`product-design.md` の F03/F07/F12/F23 を明示的に除外した判断が、このペルソナに対してすべて当たっている。

一方で、彼がアプリを2回目に開く理由が、現状のどこにも生まれていない。

## 効いている点

### 「今日決めるのは、いちばん下の1つだけ」

`#routes` 下部のこの一文と、経路4の「この経路は『今は決めない』という選択そのものです」。

彼の「めんどくさい」は興味のなさではなく、**「今この場で人生を確定させろと要求されること」への拒否**である。4つの分岐点（高校＝中3の12月／文理＝高1の11月／学部＝高3の夏／専攻＝大学2〜3年）を分解して「今日の宿題は1個だけ」と言い切るのは、このぼやきに対するおそらく唯一有効な返答。進路サイトが普通やる「逆算して今すぐ動け」の真逆で、それが正しい。

### 経路を4本並列に出したこと

彼の兄は高専生。「高専はどう？」と人から言われた瞬間、彼は反射的に閉じる。経路3（高専→大学編入）を推薦せず順位もつけず横並びにしている構造が、この地雷を踏んでいない。「あなたには高専が向いています」を1回でも出していたら、このサービスは二度と開かれない。

### 数学を門番にしていない

経路ごとに数学I・A中心／II・B＋データ／IIIまでを出し、同じ学問でも幅があると示す。「理系＝数III＝無理」と早々に自己排除しがちなタイプに、逃げ道を事実として渡している。

### 出典・確認日・「主張しない」の明記

「特定の高校からの進学実績を示すものではありません」「経路の組み立てと数学の目安は本アプリの編集です」。断定されると疑うタイプに対し、信頼のコストを一番安く払える方法。彼は「盛られている」ことを敏感に見抜く。

### 保存オフ既定と、その説明

`#saved` の保存設定に「同じブラウザを使う人が開ける場合があります」。共用端末の可能性がある環境で、**「秘密は守られます」と言わずに守られない条件を先に言った**のは正しい。

## 致命的な問題

### 1. 「一人だと続かない」に、何の設計もない

英語塾・縄跳び・筋トレが三日坊主。この人物の行動記録で一番重い事実。

このサービスは完全に一人で完結する設計で、通知もタスクもストリークも意図的に排除している（F22/F23）。排除の理由は正しいが、**代替が用意されていない**。

彼が続いているもの（ゲーム・料理・ギター）と続かなかったものの差は、意志ではなく**やったら何かができあがるか**にある。料理は皿が出る。ギターは音が出る。縄跳びは何も出ない。いまのシンボクは読んで・眺めて・メモして終わり、彼の分類では縄跳び側にいる。Build 15/16 の「前回の続き」「次の行動の提案」は再開の手がかりにはなるが、成果物が残らない限り2回目は開かれない。

### 2. カタログ13件の薄さと、年齢のミスマッチ

「ゲーム好き」→「自分でつくる」まで進んで出てきたもの：

| 出たもの | 推定される反応 |
| --- | --- |
| Scratchで小さな作品を作る | 小学生向け。Z会タブレットで自由進度学習をこなす中3には離脱理由 |
| 近くのCoderDojoを探す | 行動範囲は家と近所。継続参加＝外出＝一人だと続かない領域 |
| ギターの音色は、どこで変わる？ | これは刺さる（ギター教室に通っている） |
| 立命館大学 映像学部 / 九州大学 芸術工学部 | 中3の12月に見て「遠すぎる」 |

料理を選んでも「発酵の読みもの」1件。**週500円・自宅完結・行動範囲は家と近所という制約に合う「今日できること」が実質ゼロ。**

さらに8領域を等しく並べながら中身は海に偏る（大島海洋国際高校・同潜水部・学校説明会・東京海洋大3学部）。慎重な彼は2〜3分で「これ海の宣伝だな」に気づき、気づいた瞬間に他領域の記述も信用しなくなる。

`self-evaluation.md` で「情報の厚み」を長く3に据え置いたのは正しい自覚だが、Build 14 で他軸を4に上げて合格点24/30を出したことで、この最大の穴が見えにくくなっている。**彼にとって情報の厚みは他軸と交換可能ではない。**

### 3. 地域

`#routes` の高校段の出典が都立高校の入試案内、経路2の実例が東京都立大島海洋国際高等学校（伊豆大島・全寮制）。父が単身赴任で母と2人暮らしの中3に、離島の全寮制高校が「海に関わる高校の代表例」として据わっている。

彼は口には出さず、黙って読み替えるか、黙って閉じる。**自分から相談しない人物なので、ミスマッチはフィードバックとして返ってこない。**

「地域を聞かない」方針自体は彼の性格に合うが、今は聞かない代わりに東京がデフォルトになっている。これは「聞かない」ではなく「東京だと決めつけている」。

### 4. 「自分のマップ」の編集が作業になる

枝を作る／名前をつける／つながる理由を書く／メモを書く。完璧主義寄りの人物は「ちゃんと書かないと」で手が止まる。`product-design.md` 第2巡で「進路希望調査票のようになる」と正しく自己批判しているのに、Build 08〜13 の編集機能の積み増しで再発しかけた。Build 12 の初回導線監査で入口を興味スターターだけに戻したのは正しい修正。**「初回3分で1文字も書かずに価値が出るか」を退行テストとして固定すべき。**

### 5. 「探究」という語

`#personal` は「自分のマップ」に改称済みで良い改善。ただしコードとドキュメントには inquiry / 探究 が残る。「探究」は総合的な学習の時間の語彙で、**学校から与えられた課題**を強く連想させる。彼は「学校の課題」と「自分で見つけたもの」を厳密に区別し、前者に分類された瞬間にやる気を失う。UI文言に出さない現状を維持すること。

## 構造上の懸念

### `FAMILY_SHARING_ENABLED` フラグ

`family-api.mjs`・`/family`・結合テストが残り、フラグ1つで保護者共有が復活する。README にも明記されている。

このペルソナに対して、**共有機能は「オフになっている」では不十分**である。彼が警戒するのは「今は無効だが、いつでも有効にできる」状態そのもの。「このアプリに保護者アカウントはない」と言い切るなら、コードを消すか別リポジトリへ退避するのが筋。`self-evaluation.md` の次の改善5で保留にしているこの判断は、プロダクトの中心的価値に直結するので先送りすべきでない。

### 「見た情報」の自動記録

見たカタログ項目が自動記録され一覧になる（最大100件、端末保存オフならメモリ内のみ、外部送信なし）。技術的には潔白。

ただし**「自分が何を見たかが、自分の許可なく一覧になっている」**のは、彼が最も嫌う感触に一番近い。実害がなくても警戒レーダーに引っかかる。「見た情報」タブの初回表示時に短く説明するか、個別削除を置くこと。

## 優先して直すべき順

1. **カタログの年齢と地域の適合** — Scratch/CoderDojo が中3の「つくる」の代表例になっている状態と、都立/大島デフォルトを解消する。件数を増やすより、**1つの領域で「中3が今週やれること」を3件そろえる**ほうが効く。
2. **「一人だと続かない」への一手** — 通知ではなく成果物。1回15分で完了判定できる行動を設計する。
3. **共有機能コードの去就を決める** — 残すなら理由をプロダクトシートに書く。書けないなら消す。
4. **本人観察** — この人物は自分から相談しないため、観察でしか問題が出てこない。「どう思った？」は機能しない。無言で閉じた瞬間を記録できる形にすること。
