# シンボク — prototype Build 19

今後7年のうち、自分がいまどこにいて、次にどの扉が開くのかを確かめる拠点。
7年は中3から大学2〜3年まで。そのあいだに決める場所は4つで、今日決めるのはいちばん近い1つだけ。

偏差値からは引けない。共有機能は持たない。

- `npm start`：`http://127.0.0.1:4317` でローカルサーバー
- `npm test`：25件のテスト
- `npm run check`：データ検証とJavaScriptの構文検査
- `npm run build`：公開用の `dist` を生成（`dist` だけをアップロードする）

## 画面

タブは2つだけ。

| ルート | 画面 | 役割 |
| --- | --- | --- |
| `#now` | 7年の地図 | 4つの分岐点と保留可能期限、いまの考え、やったことの記録（既定の入口） |
| `#find` | 探す | 動詞から、活動アイデア・学問・掲載情報へ |
| `#find/<動詞>` | 動詞の詳細 | つくる／くらべる／観察する／調べる／伝える |
| `#routes/<学問>` | 進み方 | その学問にたどり着く4本の経路。「探す」から開く |

## 7年の地図（`#now`）

未来が上、いまが下のはしご。各段に **保留できる期限** がある。

| 分岐点 | 保留できる期限 |
| --- | --- |
| 専攻・研究室を選ぶ | 大学2〜3年ごろまで |
| 学部・学科を選ぶ | 高3の夏ごろまで |
| 文理・コースを選ぶ | 高1の11月ごろまで |
| 高校を選ぶ | 中3の12月ごろまで |

初期表示は下2段だけ。「もっと先まで見る」で7年全体に広がる。

各段に、本人が**1行の「いまの考え」**を残せる。**空欄が正常**で、空欄には「まだ決める段階ではありません」と出る。埋めるよう促さない。

**学年は任意。** 1タップで選ぶと「あと3か月（2026年12月ごろ）」のように残りが出る。答えなくても地図は全部見られる。日本の学校年度（4月始まり）で計算した目安で、公立の一般入試を想定している。

いちばん下の「いま」には、**やったこと**を1行で置ける。締切・連続記録・達成率は持たない。

## 動詞から逆算する（`#find`）

中学生は学問名を持っていない。持っているのは「ゲームやってる」「料理する」なので、逆算の起点を動詞にした。

```text
つくる ─┬─ ギター・音楽：映像で共演する／音楽 × 場づくり
        ├─ ゲーム：動きを作る／世界観を描く／ゲーム × 学び
        └─ 料理：家族の一皿／自分の一皿を考える／食 × 環境
             ↓ この動詞を仕事や研究として続けている学問
        映像・ゲーム表現／デザイン／情報科学／海洋工学／食品科学／音響・音楽
             ↓
        #routes：その学問にたどり着く4本の経路
```

同じ「つくる」がゲームにも料理にも音楽にも出ることが、この層の目的。活動には**目安の所要時間**と**家でできるか**が付いていて、「家でできるものだけ」で絞れる。活動の「やった」を押すと、7年の地図の「いま」に記録が残る。

動詞・所要時間・場所の割り当てはこのアプリの編集で、画面にそう書いてある。

## 進み方（`#routes/<学問>`）

Build 14 の実装をそのまま使っている。学問を選ぶと、性質の異なる4本の経路が出る。

1. 普通科 → 総合大学
2. 専門学科の高校 → 専門の大学
3. 高専 → 大学編入
4. 高校では別分野 → 大学で転向

各経路は「学問・研究 → 大学・学部 → 高校の中の選択 → 高校 → いま必要なこと」の5段。経路ごとに**必要な数学**（I・A中心／II・B＋データ／IIIまで）が違い、同じ学問でも幅が出る。

高校の段は原則として学科の型で示す。**特定の高校からの進学実績は主張しない**（検証できないため）。実在校を挙げているのは大島海洋国際高校・鳥羽商船高専・東京高専のみ。

## 記録の扱い

初期状態では記録はメモリ内のみ。「このブラウザに記録を残す」を有効にしたときだけ、学年・いまの考え・やったこと・あとで見る・見返す経路を端末に保存する。**サーバーには送らない。** 同じブラウザを使う人が開ける場合があることを画面に書いている。

Build 18 までの保存形式（`shimboku.workspace.v1`）は読まないが、消してもいない。残っている場合は保存設定でそう表示する。

## 共有機能について

このアプリに保護者アカウントはない。検索・閲覧・メモを家族や学校に共有する機能、エクスポート、通知、保護者向け画面のいずれも存在しない。

Build 07〜13 で実装した保護者共有のサーバー実装は、Build 19 で `archive/` に退避し、`server.mjs` の配信対象から外した。フラグで復活する状態も解消した。

## データ

正本は `data/knowledge.json`（`version: 2`）。編集後は `npm run knowledge:check` と `npm run knowledge:build`。

- 動詞 5、学びの領域 8、興味の入口 4、活動アイデア 36、掲載情報 42件
- 掲載情報にはすべて出典・確認日・条件が付く
- 検証が強制すること：動詞ごとに活動3件以上／活動は全件に動詞・所要時間・場所／`study` 以外の掲載情報は動詞1つ以上／領域はデータ側にだけ定義する
