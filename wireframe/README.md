今後7年のうち、自分がいまどこにいて、次にどの扉が開くのかを確かめる拠点。
7年は中3から大学2〜3年まで。そのあいだに決める場所は4つで、今日決めるのはいちばん近い1つだけ。

偏差値からは引けない。家族から届いた情報も、本人が選ぶまで野原には入らない。

## 時間の野原（`#now`）

**縦だけが時間。** 下が今日、上が7年先。段は4つの分岐点と「いま」。

| 段 | 保留できる期限 |
| --- | --- |
| 専攻・研究室を選ぶ | 大学2〜3年ごろまで |
| 学部・学科を選ぶ | 高3の夏ごろまで |
| 文理・コースを選ぶ | 高1の11月ごろまで |
| 高校を選ぶ | 中3の12月ごろまで |
| いま | ここが今日 |

**横に意味はない。** どこに置いてもよく、アプリは置き直さない。整列も並べ替えもしない。

**意味を持つのは線。** 置いたものから伸びた線が、どこで合流するか。これが一覧では出せない唯一の情報である。

### 世界は、置いたぶんだけ現れる

初期状態は空の野原。学問も経路も最初から並べない。

```text
1. 「いま」に「海・生き物」を置く
       → 生態学・環境科学・海洋工学が上の段に現れ、線が伸びる
2. 「料理・食べもの」を置く
       → 生態学に2本届く → そこが光る（合流）
3. 生態学をタップ → ここへの道は4本
       → 「高専 → 大学編入」を選ぶと、大学・文理・高校の3段に経路が引かれる
4. 置きものを上の段へドラッグ
       → 「高校に入ったらやりたいこと」として持てる
```

合流した学問の横位置は、届いている置きものの平均。合流するほど2つの間へ寄るので、収束が位置そのものに出る。

合流しなければ「まだ合流していません」と言い、無理に線をつながない。自由入力は、本人が関わり方（動詞）を選ぶまでどこにもつながない。文字列から領域を推測しない。

置けるもの：好きなこと4／活動アイデア36／掲載情報42／自分で書いたもの／見つけたページ／写真。置きものごとに「やったこと」の記録がぶら下がる。

### 置きものの形（Build 23）

```text
置きもの
├─ 出どころ：掲載情報／このアプリの項目／自分で追加／家族から（Build 25）
├─ 内容    ：リンク／写真／活動／掲載情報／好きなこと／自由入力
├─ 何について（タグ・任意）
├─ 関わり方（動詞・任意）
├─ 時間の段
└─ やったこと
```

**自分で調べたものを、そのまま置ける。** URL を貼るか、ブックマークレットで見ているページを送るか、写真を選ぶか、思いついたことを書く。

- **置く前に必ず確認画面が出る。** 何が置かれるか（リンク先の全文・写真）と、**いまの選び方だとどこへ線が伸びるか**を先に見せる。
- **通信しない。** 貼られた URL を開いて中身を取りに行かない。題名もサムネイルも取得しない。
- **推測しない。** URL や文字列から興味・領域を当てにいかない。線が伸びるのは本人がタグを選んだときだけ。
- **「何について」×「関わり方」は積集合。** 「海について」「つくる」なら海洋工学。和集合だと1つ置くだけで6領域へ線が伸び、合流が意味を失う。
- **出どころを隠さない。** 自分で足したものには「自分で追加」「内容は確認していません」を、パネルにも一覧にも、図の上（破線＋印）にも出す。
- **http と https だけ。** リンクは自動で開かず、`rel="noopener noreferrer nofollow"` で別のタブに開く。
- **写真はこの端末の中だけ。** 480pxまで縮小して1枚160KB・12枚まで。ノードには出さず（時間の軸が読めなくなるため）、選んだときのパネルに出す。

段の見出しをタップすると、その分岐点の保留期限と「いまの考え」（1行・任意・空欄が正常）を読み書きできる。

**学年は任意。** 1タップで選ぶと「あと3か月（2026年12月ごろ）」が出る。答えなくても野原は全部見られる。

**「一覧で読む」** を常設していて、段ごとの中身と合流を文章でも読める。色だけに意味を持たせない。並べ方は「時間の段」「追加順」「つながる学問」から選ぶ。どの並びでも置いたものは1つも欠けない。

### 20件置いても読めるようにする（Build 22）

置くほど線とラベルが増えるので、読めなくなる原因を次のように扱う。いずれも**描画の話**で、保存された横位置は書き換えない。

- **表示切替**：「全体を見る」「選んだものだけ」「最近置いたもの」。絞ったときは「20件のうち16件を表示しています」と件数を必ず出す。
- **まとめ**：1つの段は4行まで描き、入りきらない分は「ほか◯件」の破線チップにまとめる。線は消さずチップへ付け替える。タップまたはEnterで展開する。
- **広げる**：段ごとのトグル。その段だけ1ノード1行にして、ラベルの重なりをなくす。横位置は各自のまま、変わるのは行だけ。保存しない。
- **選んだものは隠さない**：選んだ置きものと、その線が届く学問は、まとめに入れない。
- **絞り込みは線1本ぶん**：置きものを選べばその学問まで、学問を選べばそこへ届いている置きものまで。合流相手を見たいときは、学問のほうを選ぶ。2段階のドリルダウンになる。
- **広げている段は野原の外にも出す**：広げた段は縦に長くなり、見出しの「まとめる」がスクロールで画面外へ出てしまうため。
- **線の前後**：選んだものにつながる線を前面に出す。ほかは消さずに薄くする。

**キーボードでも同じことができる。** Tabで移動、EnterまたはSpaceで開く、矢印キーで置きものを動かす（左右＝横位置、Shiftで細かく／上下＝段の移動）。段を移すと、どの段へ動かしたかを読み上げる。

**動かしている間は画面全体を描き直さない。** 動かしているノードと、そこにつながる線だけを書き換え、指を離したときに確定して保存する。

## 動詞から逆算する（`#find`）

中学生は学問名を持っていない。持っているのは「ゲームやってる」「料理する」なので、逆算の起点を動詞にした。

```text
つくる ─┬─ ギター・音楽：映像で共演する／音楽 × 場づくり
        ├─ ゲーム：動きを作る／世界観を描く／ゲーム × 学び
        └─ 料理：家族の一皿／自分の一皿を考える／食 × 環境
             ↓ この動詞を仕事や研究として続けている学問
        映像・ゲーム表現／デザイン／情報科学／海洋工学／食品科学／音響・音楽
```

同じ「つくる」がゲームにも料理にも音楽にも出ることが、この層の目的。活動には目安の所要時間と「家でできるか」が付いていて、見つけたものはその場から野原に置ける。

### 掲載情報をしぼる（Build 24）

「探す」に、掲載情報42件を絞り込む場所を置いた。**絞るのは本人が絞ったときだけ**で、学年や地域を設定しても勝手な出し分けはしない。

| 絞り込み | 規則 |
| --- | --- |
| 種類 | 教材／施設／イベント／継続活動／部活動／学校／大学 の7つ |
| 住んでいるところ | 任意。選んだ県のものと、場所に縛られないものが残る |
| オンライン | オンラインと確認できたものだけ |
| 費用 | 「無料と確認できたものだけ」。分からないものは残さない |
| 対象の学年 | その学年を含むものと、**対象が書かれていないもの**が残る（書かれていない＝対象外ではない） |
| 開催の時期 | これから／終わったもの。日付を持たないものは「これから」に残る |

**掲載範囲を偽らない。** 画面の先頭に「いま載っているのは42件です。場所のあるものは◯◯に偏っていて、全国は網羅していません」と出す。「掲載の偏りを見る」を開くと、種類ごと・場所ごと・学問ごとの件数が出る。**0件の種類や学問も0件として出す**（消すと、薄いことが隠れる）。

**位置情報は取らない。** 都道府県は本人が選んだときだけ使う。市区町村も学校名も聞かない。IPアドレスからも推測しない。選ばなくても全部見られる。

**古い情報を隠さず、消さず、そう言う。** 開催日を過ぎた／申込期限を過ぎた／確認から180日たった掲載には、カードにその旨を出す。公開済みのIDは削除しない（保存した人の記録が壊れるため）。

**リンクが生きているかは、アプリでは分からない。** アプリは通信しないので、日付から分かることしか言えない。リンク切れの確認は公開前に人が手で回す整備用スクリプトで行う。

```bash
npm --prefix wireframe run links
```

`data/knowledge.json` の公開中の掲載情報のURLをHEAD（拒まれたらGET）で確認し、リダイレクト先・4xx・5xx・時間切れを表で出す。4xx/5xx があれば終了コード1。**データは書き換えない。**配信物にも含まれない。

## 進み方（`#routes/<学問>`）

Build 14 の実装をそのまま使っている。学問を選ぶと、性質の異なる4本の経路が出る。

1. 普通科 → 総合大学
2. 専門学科の高校 → 専門の大学
3. 高専 → 大学編入
4. 高校では別分野 → 大学で転向

各経路は「学問・研究 → 大学・学部 → 高校の中の選択 → 高校 → いま必要なこと」の5段。経路ごとに**必要な数学**（I・A中心／II・B＋データ／IIIまで）が違い、同じ学問でも幅が出る。

高校の段は原則として学科の型で示す。**特定の高校からの進学実績は主張しない**（検証できないため）。実在校を挙げているのは大島海洋国際高校・鳥羽商船高専・東京高専のみ。

## 記録の扱い

初期状態では記録はメモリ内のみ。「このブラウザに記録を残す」を有効にしたときだけ、学年・いまの考え・やったこと・あとで見る・見返す経路を端末に保存する。**サーバーには送らない。** 同じブラウザを使う人が開ける場合があることを画面に書いている。

Build 18 までの保存形式（`shimboku.workspace.v1`）は読まないが、消してもいない。残っている場合は保存設定でそう表示する。

## 家族からのおすすめ（Build 25）

家族用画面で名前・URL・一言・任意のタグを1件の共有リンクにできる。本人がリンクを開くと「家族からのおすすめ」受信箱へ入り、「野原に置く」「あとで見る」「受信箱から消す」を本人が選ぶ。野原へ置いたものには「家族から」「内容は確認していません」と表示する。

共有リンクに入るのはその1件だけで、本人の野原・記録・学年・保存内容は家族側へ渡らない。現在は体験検証用の静的実装であり、アカウント、継続接続、通知、複数端末同期は持たない。サービス化する認証・DB・API・権限と移行順は `../docs/service-architecture.md` を正とする。

Build 07〜13 の旧共有サーバーは現在の体験・権限モデルと異なるため、Build 19 で `archive/` に退避した。Build 25 は旧実装を復活させず、本人の受信箱から作り直している。
